# 🐾 小小動物醫院

給幼稚園小朋友的溫和節奏醫院小遊戲：小動物病人來掛號，把他們拖到病床上、選對治療工具，治好了就能收到愛心。

**線上遊玩**：https://tsun-u.github.io/tsunu-hospital/

## 玩法

1. 小動物從門口進來候診區，頭上會冒出症狀泡泡
2. 把病人拖到空病床
3. 從下方工具架拖正確的工具過去：冰枕退燒、藥水治肚子痛、OK繃貼擦傷、面紙擤鼻涕、牙刷刷蛀牙
4. 治好的病人開心出院，愛心 +1
5. 愛心累積會有新的動物朋友來掛號（總共 10 種常駐＋4 種神祕嘉賓）

沒有失敗、沒有倒數：等太久的病人只會哭哭，點一下拍拍安撫就好，他們永遠不會生氣離開。

## 特色

- 介面無文字依賴，所有狀態都用動畫和圖示表達，還不識字的小朋友也能玩
- 支援中文／台文／台羅三種語言顯示
- 觸控優先設計，平板可直接用 Chrome「加到主畫面」當 app 玩
- 純前端零依賴，進度存在瀏覽器裡，隨時關掉隨時回來

## 開發

單一 `index.html` ＋ `strings.js`（介面字串翻譯檔），無建置步驟，clone 下來直接開就能玩。

遊戲參數（病床數、掛號間隔、解鎖節奏等）集中在 `index.html` 頂部的 `CONFIG` 物件，歡迎自行調整。
